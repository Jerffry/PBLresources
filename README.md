### 一、这个智能体是什么

「格物」将论文的五步教学策略（跨学科全球议题选择 → AIGC动态资源生成 → 分层教学目标设计 → "导学伴"智能体实训 → 数据驱动逆向教学设计）产品化为一个备课智能体：

- **输入**：课题名称（如"海洋空间资源开发与国家安全"），可选学情、课时、技术环境
- **过程**：六个节点（N0课题解析 + N1～N5对应五步策略 + N6整合输出），每一步教师在环、可改再生成
- **输出**：教学设计方案包六件套（教学设计文档、SOLO分层目标表、评价量规、跨学科资源包、实训脚本、课堂智能体配置）

基本逻辑：**以逆向教学设计（目标→评价→内容）为主线，五步策略为功能模块，学情数据回流为闭环。**

### 三、快速开始（两种方式）

**方式A：任意大模型直接使用（5分钟）**
1. 新开一个对话（DeepSeek、豆包、Kimi、智谱清言等均可，建议开启长上下文）；
2. 将 [02_总控系统提示词.md](02_总控系统提示词.md) 中的系统提示词整段粘贴发送；
3. 输入课题名（例如"海洋空间资源开发与国家安全"），智能体即从 N0 开始逐节点推进；
4. 需要精细控制某个节点时，把 [03](03_节点提示词_N0-N3.md)、[04](04_节点提示词_N4-N6.md) 中对应节点的提示词追加发送。

**方式B：低代码平台部署（面向校内推广）**
按 [05_低代码平台搭建指南.md](05_低代码平台搭建指南.md) 在扣子或 Dify 上配置知识库与工作流，发布给教研组使用。

### 五、演进路线

- **V1（本资料包01-07）**：教师备课端，提示词工作流形态，任意大模型可跑；
- **V2（当前，已上线）**：扣子页面编辑器自定义应用——双模式（🌍全球胜任力 N 线＋🧩跨学科主题 M 线）、项目持久化、节点进度可视化、四级徽章，校内推广；
- **V3**：课堂端"导学伴"上线（学生直接对话），接入希沃课堂数据，实现 SOLO 学情回流闭环，构建"技术—学科—能力"评价体系。
